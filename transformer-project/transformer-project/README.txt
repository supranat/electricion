โครงงานหม้อแปลงไฟฟ้า - แบบจำลองอ้างอิง EE-05

วิธีเปิดดู   : เปิด index.html หรือให้บริการผ่านเว็บเซิร์ฟเวอร์ในเครื่อง
ไลบรารี 3D : โหลด Three.js จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต
ข้อมูลชิ้นส่วน: แก้ไฟล์ js/data.js (PROJECT คือสเปกระบบ, PARTS คือชิ้นส่วน)
ค่าจัดวางชิ้นส่วนหลัก (LAYOUT) คำนวณจาก PARTS เพื่อให้ตำแหน่งคาน เสา และสายสอดคล้องกัน
ปรับฉากและเรขาคณิต: แก้ไฟล์ js/scene.js
เปลี่ยนหน้าตา : แก้ไฟล์ css/style.css
โฟลเดอร์ images/: เก็บภาพประกอบที่ได้รับอนุญาตให้นำมาใช้

หน่วยขนาดและตำแหน่งใน js/data.js เป็นเมตร:
- box: size [กว้าง, สูง, ลึก]
- cyl: size [รัศมีบน, รัศมีล่าง, สูง]
- pos: [x, y, z] ตำแหน่งจุดกึ่งกลาง
- rot: [x, y, z] องศา (ไม่บังคับ)
- ทุกชิ้นส่วนต้องมี id ที่ไม่ซ้ำ, name, shape, size, pos และ spec

โมเดลประกอบนี้อ้างอิงรายการและค่าที่ให้มาสำหรับแบบ EE-05 โดยไม่แสดงชื่อ
บริษัทเจ้าของงาน ชื่อวิศวกร หรือเลขใบอนุญาต ขนาดตู้แรงต่ำและระดับแนวคาน
บางส่วนประเมินจากสัดส่วนภาพเพื่อการแสดงผลเท่านั้น และระยะห่างเสาประมาณ
4.2 ม. ยังต้องตรวจเทียบกับระยะจริง แบบอนุมัติ และสภาพหน้างาน

แบบต้นฉบับระบุ DO NOT SCALE โมเดลนี้ไม่ใช่แบบก่อสร้าง แบบติดตั้ง
หรือเอกสารใช้สั่งผลิต ห้ามใช้ขนาด/ตำแหน่งในโมเดลออกแบบหรือติดตั้งจริง
ต้องตรวจสอบแบบอนุมัติ รายละเอียดผู้ผลิต และวิศวกรผู้รับผิดชอบก่อนดำเนินงาน

หากโหลด Three.js ไม่ได้, ข้อมูลไม่ครบ หรือ WebGL ใช้งานไม่ได้ จะแสดง
ข้อความแจ้งเตือนบนหน้าเว็บ รายละเอียดประกอบเป็นภาพจำลอง ไม่ใช่สเปกจริง
